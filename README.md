# India Info Web Project

**[live](https://rutik-1.github.io/Bharatsya-Gyanam/)**

Welcome to the **India Info** web project! 🇮🇳  
This project is a comprehensive and visually engaging resource for learning about the states and union territories of India. Each page provides key facts, traditional attire, historical background, images, and local words for every state.

## Features

- **State-wise Information:**  
  Each Indian state and union territory has its own dedicated HTML page with:
  - Capital, Chief Minister, Largest City, Districts, Official & Other Languages, Population, Area, Major Rivers, Major Industries, Popular Places
  - Traditional dresses and cultural highlights
  - Concise historical overview
  - Image gallery of famous places and culture
  - Local words or phrases with translations

- **Modern Design:**  
  - Responsive layout using CSS Flexbox and media queries
  - Clean, readable typography and color palette
  - Interactive image hover effects

- **Navigation:**  
  - Home page with a hero section and gallery of popular places
  - About page describing the project’s mission


## Project Structure

```
bharat info/
├── index.html                # Home page
├── about.html                # About the project
├── Aindiainfohub.html        # Interactive India map (SVG)
├── [State].html              # One file per state/UT (e.g., west bengal.html, odisha.html, etc.)
├── style.css                 # Main stylesheet
├── img/                      # Images for galleries
└── README.md                 # Project documentation
```

## How to Use

1. **Clone or download** this repository.
2. Open `index.html` in your browser to start exploring.
3. Click on states or use navigation links to view detailed information.

## Technologies Used

- HTML5 & CSS3 (with responsive design)
- [Tailwind CSS](https://tailwindcss.com/) (for About and Home pages)
- Google Fonts (Inter)
- SVG for interactive India map
